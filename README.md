# 🍽️ Restaurant Recommendation System

Content-based filtering system that recommends restaurants to users based on cuisine, ratings, and other features from a custom dataset.

## 🎯 Problem Statement
With hundreds of restaurant options available, users often struggle to find restaurants matching their taste. This project builds a recommendation system that suggests similar restaurants based on content-based filtering techniques.

## 📁 Dataset
- Custom restaurant dataset including cuisine type, location, ratings, and price range

## 🔍 Approach
- Used content-based filtering to compute similarity between restaurants
- Recommended top restaurants based on feature similarity (cuisine, ratings, etc.)

## 🛠️ Tools Used
- **Python** — Pandas, Scikit-learn
- **Jupyter Notebook** — Analysis and model building

## 📌 How to Run
1. Download the `.ipynb` file from this repository
2. Open it in Jupyter Notebook or Google Colab
3. Run all cells to see the recommendation results
